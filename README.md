# Break, Build, Learn

A space to explore interests, run experiments, build projects, and reflect on learning.

## Structure

- [Philosophy](philosophy/learning-in-the-ai-era.md): principles for learning in the AI era.
- [JEE 2028](JEE%202028/README.md): study routines, preparation advice, and resources for JEE alongside ALLEN coaching.
- [Exploration tracks](exploration-tracks/): gaming, artificial intelligence, software development, robotics, creativity, and entrepreneurship.
- [Experiments](experiments/): small, focused attempts to test ideas.
- [Projects](projects/): turn promising experiments into working creations.
- [Learning journal](learning-journal/): record discoveries, challenges, and next steps.
- [Skills](skills/): track and practice capabilities.
- [Resources](resources/): collect useful references and tools.

## Getting Started

1. Pick an exploration track and a question you want to investigate.
2. Use an experiment folder to record your question, approach, and results.
3. Build something small, test it, and note what happened.
4. Reflect in your learning journal and choose your next step.
